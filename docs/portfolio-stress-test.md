# Portfolio stress-test lesson ledger

A technical portfolio was used as a repeated real-world evaluation of Representation Router. The goal was not to encode one site's aesthetics; it was to expose general routing failures.

## Lessons that became router rules

1. **Structure is not explanatory focus.** A network may need a graph for structure inspection or a staged/flow explanation when transformation is the concern.
2. **Representation role matters.** A reviewer-facing caricature, an analyst workbench, and an audit surface can project the same semantic model differently.
3. **Primary concern beats assurance mechanics.** Hardening, validation, audit, pooling, guardrails, and provenance can be vital without deserving headline status.
4. **Representation of a stage is not representation of the system.** Multi-stage methods may need persistent explanatory machines even when one stage is naturally a matrix/table/graph.
5. **Preserve identity only while identity persists.** Evidence may become an aggregate, judgment, graph edge state, or result; do not force one token/mark through every stage.
6. **Semantic adjacency is not semantic identity.** Evidence-related objects are not all evidence marks.
7. **Animate operations, not transport.** Emit, dock, classify, transform, ground, pool, synthesize.
8. **Scrubbed states and autoplay have different jobs.** Autoplay can show accumulation; scrubbed states should be complete and inspectable.
9. **The payoff must explain the product.** A final frame named with internal artifacts is a failure if a newcomer still cannot say what the system returns.
10. **Repeated surfaces need collection rules.** Heterogeneous representations can share semantic marks, activation/focus/exit behavior, typography/quality constraints, and control placement without becoming visually identical.
11. **UI color is not semantic color.** Card selection/accent styling should not reuse colors whose meaning is already bound to claims, states, entities, evidence, etc.
12. **Geometry QA is not comprehension QA.** Bounding boxes catch overlap; a novice readback catches unintelligible purpose, jargon, and missing payoff.
13. **Learning goals are not implementation capabilities.** State the desired learner outcome (prediction, discrimination, transfer, fluency) and let the router infer scaffolding and assessment patterns instead of requiring callers to know the pedagogy catalog.

## Protected examples

`examples/portfolio-*.json` encode newcomer-facing explanatory cases for qualitative analysis, adaptive graph retrieval, conditional simulation, collective competence, agent interchange modeling, and an ecosystem-aware agent control plane.

The test suite also contains adversarial cases where the same network changes representation when explanatory focus/role changes, and where assurance legitimately becomes primary for a verification stakeholder.
