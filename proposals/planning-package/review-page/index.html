The router picks how information is shown to a person: which view answers their question, how the whole page reads, and which checks the built page must pass. It also ships the shared graph viewer other projects draw with. This package records what exists, what was checked, what is still open, and the next plan: make sure a dense graph never freezes a page (issue #169). What you do: Nothing is waiting on you. Every open question is an agent's to settle; read the plan if you want to change what comes next: start at the review page.
