Project flow

Five capabilities · one human review checkpoint · one feedback loop

01Implemented

Define prospect criteria

Keywords, accounts, and simple qualification rules define who the project is looking for.

Evidence

Targeting inputs and a repeatable qualification step are explicitly represented.

Does not prove

The targeting rules do not prove the chosen audience is commercially valuable.

→
02Implemented

Collect candidate posts

A source adapter gathers candidate posts or profiles that match the configured search criteria.

Evidence

Collection is a distinct source-bound capability in the project flow.

Does not prove

This demo does not claim live Twitter/X API access, credentials, rate-limit handling, or production ingestion.

→
03Partial

Score relevance

Candidates are ranked using simple relevance signals so the reviewer sees the strongest prospects first.

Evidence

Ranking is explicitly separated from collection and human review.

Does not prove

A ranking function is not evidence that the ranking predicts conversion or business value.

→
04Partial

Review prospects

A human reviews candidate context, rejects weak matches, and keeps promising prospects.

Evidence

Human review is explicit rather than implied as an automatic decision.

Does not prove

This view does not authorize outreach or mutate an external CRM.

→
05Planned

Export shortlist

Approved prospects can be handed off as a small shortlist for a downstream outreach or CRM workflow.

Evidence

The handoff boundary is explicit in the project model.

Does not prove

No external write, message send, or CRM update is implemented or authorized by this fixture.

↺ Review informs targeting refinement. Human review can suggest better prospect criteria, but this artifact does not automatically rewrite source configuration.

What this view makes clear

  • The project is a simple pipeline, not a general-purpose social intelligence platform.
  • Collection and qualification criteria exist before scoring and review.
  • Scoring and human review are incomplete, and export is still planned.
  • Human review is an explicit boundary before any downstream handoff.
